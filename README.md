Tech Stack: Kotlin, Jetpack Compose, Retrofit, Coroutines, OpenWeatherMap API

Description: Designed and developed a fully functional weather application using Jetpack Compose and Retrofit to provide real-time weather updates. The app interacts with the OpenWeatherMap API to fetch weather data for a user-specified city and displays it in a clean, responsive UI.

Key Features:

City-Based Weather Search: Users can input any city to view current temperature, weather condition, humidity, and other metrics.

Dynamic UI with Jetpack Compose: Built with a declarative UI approach to simplify and modernize the interface.

Retrofit Integration: Implemented a robust REST client to fetch weather data using Retrofit and parse JSON responses with Gson.

Coroutines for Asynchronous Calls: Used Kotlin Coroutines for seamless background network operations, improving app responsiveness.

Error Handling & Loading States: Handled exceptions gracefully and provided user feedback during API calls.
